Download the results of a request

Please use the Query interface to submit your search. All result tables can be downloaded in different formats, including CSV as listed on the Download tab of the Query interface.

Download formats

Comma-separated Values A text file with a line for each row of the table. The fields are delimited by a comma and enclosed by double quotes. Use this option for a later import into a spreadsheet application or a custom script. Use this option if you are unsure what to use.
IVOA VOTable XML file A XML file using the IVOA VOTable format. Use this option if you intend to use VO compatible software to further process the data.
FITS File Standard format for astronomical tables.
